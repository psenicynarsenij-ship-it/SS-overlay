# Design Preview на Windows 11

В GitHub Actions откройте последний успешный запуск **Design Preview Windows x64** для PR № 2.
Скачайте артефакт **SS-Overlay-Design-Preview**, распакуйте ZIP и дважды нажмите
**SS-Overlay-Design-Preview.exe**. .NET SDK, Visual Studio и отдельно установленный .NET Runtime
не требуются. Это self-contained Windows x64 приложение; распаковка встроенного native runtime
во временный каталог при первом запуске является штатным поведением .NET single-file.

Три вкладки: Tactical Dark, Fluent Dark, Esports Neon. Каждая содержит макет программы слева
и макет уведомления справа. Только переключение вкладок: никаких подключений к игре или
рабочим модулям нет. При небольшом разрешении используйте вертикальную прокрутку.

В том же запуске доступен артефакт **SS-Overlay-Design-Preview-Screenshots** с тремя PNG.
Их создаёт на Windows само WPF-приложение через RenderTargetBitmap после переключения вкладок
и завершения layout. Это настоящий рендер WPF-контента, не вручную нарисованные изображения
и не снимки рабочего стола/системной рамки окна. CI создаёт файлы в docs/design/;
они передаются артефактом, автоматически в Git не коммитятся.

Исполняемый файл пока не подписан сертификатом издателя: Windows может показать предупреждение
о неизвестном издателе. Production-приложение этими изменениями не затронуто.
