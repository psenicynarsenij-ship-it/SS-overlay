# SS Overlay — Fluent Dark production

Ветка `feat/fluent-dark-redesign` создана от проверенного `b76ed38` рабочей ветки.
Стиль выбран по актуальному Fluent Dark из PR № 2, код DesignPreview в рабочее приложение не подключался.

## Запуск без SDK

В успешном запуске Build and test скачайте `SS-Overlay-Fluent-Dark`, распакуйте всю папку
и откройте `SS-Overlay.exe`. .NET runtime включён; необходим VC++ Redistributable x64 для Tesseract.
Не переносите только EXE: рядом находятся OCR DLL, модель, стандартный WAV и demo fixtures.

## Реальные настройки

Сверху — последние достоверные HP, confidence, активность источника и последнее событие.
Главная кнопка переключается между запуском и остановкой. Профиль Invoker включается вручную.
Вкладки: Предупреждения / Оверлей / Звук / Дополнительно. Журнал раскрывается отдельно.
Настройки сохраняются кнопкой, путь прежний: `%LOCALAPPDATA%/DotaHpAlert/settings.json`.
Старые JSON без новых полей совместимы: стандартный звук, пользовательская позиция, анимация включена.
Параметры блокируются на время захвата; выключить профиль и остановить обработку можно сразу.

Позиционные пресеты используют основной монитор в WPF DIP, пользовательская позиция позволяет
отрицательные координаты для остальных мониторов. Существующий перенос окна из-за пределов всех
мониторов сохранён. Анимация появления — 170 мс, выключается настройкой и автоматически при
`SystemParameters.ClientAreaAnimation=false`. HP не меняет горизонтальное выравнивание.

## WAV / MP3

Выберите локальный WAV или MP3. Файл копируется под уникальным именем в папку данных приложения,
проверяется в фоновом потоке; исходник можно затем удалить. Поддерживается mono/stereo 8–192 кГц,
до 20 МБ, длительность до 60 секунд. Неудачный импорт удаляет только новую копию.
MP3 декодируется Windows ACM через имеющуюся NAudio.WinMM, без новых UI/аудиофреймворков.
WAV должен декодироваться в sample provider NAudio (PCM/float и поддерживаемые варианты).

«▶ Прослушать» использует тот же сериализованный аудиоканал, что реальные предупреждения:
звуки не накладываются, громкость программная, системный микшер не меняется.
«Стандартный» возвращает оригинальный WAV. Выбор и громкость сохраняются кнопкой настроек.
При пропавшем/повреждённом/неподдерживаемом файле проверка перед проигрыванием сообщает ошибку,
используется встроенный WAV и сбрасывается сохранённый путь. Сбой устройства вывода отдельно
диагностируется маршрутизатором и не блокирует оверлей.

Локальное полное декодирование FFmpeg прошло для каждого. У трёх есть встроенная PNG-обложка;
она не участвует в аудио. **Эти файлы не опубликованы в Git или артефакте:** права на распространение
не подтверждены. Их можно импортировать на своём ПК. Windows CI проверяет MP3 на оригинальном
тестовом сигнале проекта, а не на пользовательских файлах. Проверка FFmpeg не равнозначна
прослушиванию этих файлов или их декодированию Windows ACM на ПК пользователя.

## Проверки и ограничения

Сохранены старые тесты OCR (2298 и 59 HP), AlertEngine и маршрутизатора. Дополнены тесты
импорта/ошибок/fallback, обратной совместимости JSON и новых полей, MP3/повреждённого файла Windows.
WPF-тесты рендерят каждую вкладку в логических размерах 1920×1080 для 100%, 125%, 150%.
Это проверка layout соответствующих viewport, не переключение системного DPI и не визуальное
ручное ревью на трёх физических мониторах. Изображения доступны артефактом
`SS-Overlay-Fluent-Dark-Screenshots` и являются настоящими WPF-рендерами, не рисунками.

Не запускались Dota 2, реальный игровой захват, физическое аудиоустройство или пользовательская
мультимониторная конфигурация. Эти проверки остаются для Windows 11 с игрой.
Не добавлено распознавание анимаций Sun Strike, героя или смерти.
