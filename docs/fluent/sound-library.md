# Встроенная библиотека звуков

В PR № 3 импорт заменён готовой библиотекой. Пользователь отдельно подтвердил право публичного
распространения всех пяти переданных MP3; в сборку входят оригинальные байты, без замены.

| ID настроек | Название | Файл |
|---|---|---|
| standard | Стандартный сигнал | hp-alert.wav |
| chime | Звонкий сигнал | short-loud-chime.mp3 |
| error | Уведомление об ошибке | error-notification.mp3 |
| steam | Steam — уведомление | steam-.mp3 |
| message | Сообщение доставлено | delivered-message-sound.mp3 |
| achievement | Достижение | steam-achievement.mp3 |

На вкладке «Звук» — шесть карточек, у каждой ▶ и «Выбрать». Выбранная карточка выделена
и подписана «Основной звук». Прослушивание не меняет выбор. Общая громкость и выбор автоматически
сохраняются в прежнем settings.json. Для низкого HP и повторов используется сохранённый ID.
Импорта, диалога выбора файла и чтения внешнего SoundFilePath больше нет. Старый JSON с таким полем
совместим: путь игнорируется, используется стандартный сигнал; остальные настройки сохраняются.

Сериализация звука остаётся в NotificationRouter: второй сигнал не запускается, пока первый
не завершён. Ошибка открытия/декодирования, запуска или проигрывания MP3 приводит к одной попытке
стандартного WAV. Ошибка самого WAV возвращается в диагностику без бесконечного повтора.
Выход устройства Windows может быть выключен/недоступен — fallback не исправляет аппаратный сбой.
Громкость программная, системный микшер не меняется.

Публикация по умолчанию завершается ошибкой при отсутствии любого из пяти MP3. Windows CI
проверяет наличие всех шести файлов и SHA-256 оригинальных MP3 в publish-папке перед загрузкой ZIP.
Артефакт `SS-Overlay-Fluent-Dark` включает готовую библиотеку в `sounds/`; копировать файлы вручную не нужно.

Тесты покрывают выбор и рестарт для каждого ID, громкость, старые настройки, неизвестный ID,
fallback всех пяти MP3. Windows проверяет полное декодирование всех шести, преобразование в PCM
и фактический путь AlertSoundPlayer.Play с тестовым аудиовыходом, включая fallback после ошибки.
Это не проверка слышимости на физических динамиках: устройства звука и Dota 2 здесь не тестируются.
