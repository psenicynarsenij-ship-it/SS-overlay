# Dota HP Alert

Фундамент внешнего оверлея для Windows 11. C#, .NET 8, WPF.
Захват экрана, OCR, распознавание героя, звук и реальные уведомления пока не реализованы.

## Архитектура и правила

Core — обычная переносимая библиотека без Windows, WPF, OpenCV и внешних зависимостей.
`HealthReading` хранит абсолютное HP, время измерения, уверенность 0–1, достоверность
и необязательный признак жизни. `AlertSettings` — неизменяемый record с настройками по умолчанию
из задания. Изменения применяются через `AlertEngine.UpdateSettings`; отключение Invoker
немедленно возвращает Reset для активной тревоги, без ожидания следующего измерения.

`Evaluate` возвращает действие (None/Show/Repeat/Reset), итоговое состояние (Idle/Active),
причину и флаги звукового/визуального канала. Core сам ничего не показывает и не проигрывает.
Методы следует вызывать последовательно из одного потребителя.

При включённом Invoker достоверное HP < 350 активирует тревогу. Повторы разрешены
каждые 5 секунд. HP >= 375 сбрасывает её. Диапазон 350–374 сохраняет состояние:
для Idle уведомлений нет, для Active продолжаются повторы с тем же интервалом.
Reset выдаётся только при переходе Active → Idle; повторные сбросы возвращают None.
Известная смерть сбрасывает тревогу; неизвестный статус жизни не блокирует достоверное HP.
Недостоверное измерение не активирует, не повторяет и не сбрасывает тревогу.
Отрицательное HP и некорректная уверенность также считаются недостоверными.
Дополнительный порог уверенности не задан: решение о достоверности принимает будущий поставщик данных.

Интервал проверяется по монотонным отметкам внедрённого `TimeProvider`,
а не по времени измерения. Это защищает интервал от скачков системных часов.
Проверка давности и порядок измерений остаются ответственностью будущего источника данных.
Тесты и демо используют виртуальные часы без ожидания.

App — только WPF-каркас с окном-заглушкой и ссылкой на Core. Demo — отдельное консольное
приложение, показывающее решения движка без зависимости от Windows.

## Сборка и проверка

Нужен .NET 8 SDK (global.json разрешает новые feature band версии 8.0).
Из корня репозитория на Linux или Windows:

```sh
dotnet test tests/DotaHpAlert.Tests -c Release
dotnet run --project src/DotaHpAlert.Demo -c Release
dotnet build DotaHpAlert.sln -c Release
```

В App включён EnableWindowsTargeting: WPF можно кросс-собрать на Linux,
но запуск и визуальная проверка требуют Windows 11 с .NET Desktop Runtime 8
(или SDK с desktop runtime).
На Windows выполнить:

```powershell
dotnet run --project src/DotaHpAlert.App -c Release
```

Ожидается окно «Dota HP Alert» с текстом-заглушкой. На Linux WPF не запускать.
GitHub Actions выполняет тесты, демо и сборку App на Linux и Windows.

Демонстрация: 800 → 500 → 349 → 320 → 320 → 400 в моменты 0, 1, 2, 3, 7, 8 секунд.
Ожидаемые действия: None → None → Show → None → Repeat → Reset.
